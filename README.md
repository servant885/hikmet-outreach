# Hikmet Outreach V5
GitHub Pages: dört dosyayı repository köküne yükleyin. Settings > Pages > main / root. Siteyi açıp kurulum sihirbazını izleyin. Google Cloud YouTube Data API v3 ve OAuth web client gerekir; Gemini veya OpenAI API gerekmez. Google hizmetlerinin yaş ve kullanım koşullarına uyun.

Video taramasından sonra 100 yorumluk JSON paketlerini indirin. ChatGPT'ye her paketi yükleyip dosyadaki talimatı uygulamasını ve JSON sonuç dosyası vermesini isteyin. Sonuçları aynı açık site oturumuna aktarın. Yalnızca açık sorular ve bilgi talepleri sıralanır. Yorumcu isimleri dışa aktarılmaz, ancak yorum metni kişisel bilgi içerebilir; paylaşmadan önce kontrol edin. Sayfayı yenilemek taramayı ve ayarları siler. İçe aktarmadan önce düzenlediğiniz taslakları kaydedin; yeni aktarım listeyi yeniden oluşturur. Alt yorumlara doğrudan API yanıtı yerine YouTube bağlantısını kullanın. Her yayın ayrı onay gerektirir. ChatGPT aktarımı manueldir ve kullanım sınırları geçerlidir. API anahtarını GitHub'a yüklemeyin. Canlı API testi yapılmamıştır.
