# Hikmet Outreach V6
Dört dosyayı GitHub Pages repository köküne yükleyin. Mevcut V5 kurulumunu ilk kez V6 açıldığında yeniden girin. API anahtarı ve OAuth Client ID localStorage içinde saklanır; ayarları sil düğmesi bunları kaldırır. API anahtarını kendi web siteniz ve YouTube Data API ile kısıtlayın. localStorage şifreli değildir; ortak cihazda kullanmayın. OAuth tokeni yalnızca bellekte tutulur. Google hizmetlerinin yaş ve kullanım koşullarına uyun.
Taramadan sonra tek JSON indirin, ChatGPT’ye yükleyin ve dosyadaki talimatı uygulamasını isteyin. Yorum metinleri kişisel bilgi içerebilir; paylaşmadan önce kontrol edin. Büyük dosyalarda analiz birden fazla tur gerektirebilir. Sonuçları aynı açık oturuma aktarın. Sayfayı yenilemek taramayı siler ancak ayarları korur. Sistem açık ve anlamlı bilgi taleplerini seçer; kişisel kırılganlık veya dinî kimliğe göre hedefleme yapmaz. Her yayın ayrı onay gerektirir. Alt yorumlar için YouTube bağlantısını kullanın. Canlı API testi yapılmamıştır.
